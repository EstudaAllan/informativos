# Informativos STF · STJ

Site de estudo dos informativos de jurisprudência do STF e do STJ (2021 em diante): busca, filtros, progresso de leitura, cronograma, flashcards, Modo Prova (Certo ou Errado) e revisão espaçada.

- `index.html`: o site inteiro (HTML, CSS e JavaScript).
- `data/manifest.json`: lista dos arquivos de dados.
- `data/meta-<TRIBUNAL>-<ANO>.json`: julgados (título, processo, tese/destaque, resumo).
- `data/txt-<TRIBUNAL>-<ANO>.json`: fundamentação e legislação, carregadas sob demanda.

Fontes: planilha de dados estruturados do Informativo STF e pesquisa oficial do Informativo de Jurisprudência do STJ. Textos oficiais dos tribunais, reproduzidos com citação da fonte.

O progresso de estudo fica salvo no navegador de cada pessoa (use a aba Backup para levar a outro aparelho).
